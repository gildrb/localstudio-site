DLTL: Local Studio quick sheet

Run the /setup prompt first for a full install. This sheet only operates an existing install at http://localhost:8080.

Rules:
- Never use max_tokens.
- For vLLM/SGLang, never add --disable-cuda-graphs or --enforce-eager.
- Keep keys in env or app settings. No secrets in logs, diffs, or commits.

Verify:
1. Each controller answers GET /status, /gpus, /v1/models.
2. Providers are OpenAI-compatible upstreams created via POST /studio/providers on the active controller; route as provider/model.
3. Settings switches controllers and System shows runtime state.
4. /agent completes one turn with the selected model and local tools.
