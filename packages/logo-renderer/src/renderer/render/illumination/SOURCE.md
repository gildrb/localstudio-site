# Additive illumination of the approved atmosphere

The medium is the existing `shaders/postprocess/hero-atmosphere.wgsl`, adapted from https://vgpu.sh/examples/adaptive-quality/source.md (`field.wgsl`). Its noise, four fBm octaves, density, drift, ray coordinates and parallax are copied exactly into the added-light shader to leave the approved shader and look unchanged. Consolidating these functions requires a byte-identical baseline proof; the first isolated candidate deliberately does not refactor that shader.

Incident linear radiance uses the exact selected back-right studio configuration from the chrome's existing cubemap bake: sRGB-decoded color × intensity × luminance (global intensity is 1). Selection follows `r.isLight`, not the sky's `environmentTheme`: the dark studio peak is 3, the light studio peak is 0.5. Host gain 0.72 multiplies that actual emitter. The angular phase integrates to 1 over the sphere. The reused HDR bloom/presentation follows Vercel VGPU Prism at commit `e1661e3385ac63dc88535c1a0e819e52702f02f8`, path `apps/docs/app/[lang]/(home)/components/prism-background/`. Copyright (c) 2025 Vercel, Inc. Full MIT notice in `LICENSE`; postprocess attribution is also retained beside its copied shaders.

This candidate adds continuous, density-weighted white scattering. It does not replace the atmosphere, create ribbons/cones/endpoints, add particles or a new room, or relight the chrome material. The whole closed mesh casts source-view shadows; a fitted projector covers every caster and treats outside rays as unobstructed, not a fictional spotlight boundary. Camera coverage is independently opaque and uses the exact depth-opening transform. BOTH new display-layer increments are excluded from this coverage after all diffusion, because the existing metallic material intentionally has alpha 0.92. The approved foreground atmosphere is unchanged. Setting lightGain to zero uses the original direct render path.
