# Local Studio landing page

A close front-page recreation of [localstudio.ai](https://localstudio.ai), built with React, TypeScript, CSS, Vite, and [Motion](https://motion.dev/).

## Run

```sh
pnpm install
pnpm dev
```

Production checks:

```sh
pnpm lint
pnpm build
pnpm preview
```

## Structure

- `src/components` — reusable navigation, links, icons, and brand elements
- `src/sections` — page-level content sections
- `src/styles/global.css` — design tokens, shared visuals, and responsive rules
- `public/images` — locally served product imagery
- `public/fonts` — local Geist font assets
