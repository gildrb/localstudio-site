# localstudio.ai

Bun (1.4.0) is the package manager, bundler, dev server, and test runner: `bun install`, `bun run dev`, `bun run build`, `bun test tests/unit`. No Vite, no pnpm, no Node dependency.

### Acknowledgements

The renderer and model is built with heavy inspiration from https://eve.dev. We thank the creators of Vercel for their talents and design sense.
